# BREADBOARD_README

```bash
Pi GPIO Header
+------------+
| Pin 3 (SDA)|----+---> BME280 SDA
| Pin 5 (SCL)|----|-+-> BME280 SCL  
| Pin 1 (3.3V)|----|-|--> BME280 VCC
| Pin 6 (GND)|----|-|--> BME280 GND
+------------+    | |
                    | +---> DFR0553 C (Blue)
                    +-----> DFR0553 D (Green)
                        --> DFR0553 + (Red)  
                        --> DFR0553 - (Black)
```
